# Jaade

Jaade is an agent workspace for building, operating, and coordinating software work.

This repository is the public home for Jaade information. The product source code is not hosted here.

## Links

- Website: <https://jaade.app>
- Changelog: <https://jaade.app/changelog>
- Releases: <https://github.com/jaadehq/jaade-public/releases>
- Issues: <https://github.com/jaadehq/jaade-public/issues>

## What belongs here

Use this repository for:

- release notes and public downloads
- bug reports
- feature requests
- public roadmap and product discussions, when available

Please include clear reproduction steps for bugs, including your operating system, Jaade version, expected behavior, and actual behavior.

## Source Code

Jaade is not fully open source at this time. This public repository exists for communication, issue tracking, and releases.
